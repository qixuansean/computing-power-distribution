# OCN Mind 1B Benchmark Specification

## 1. Performance Metrics
- Task Understanding: Accuracy, F1-score.
- Resource Prediction: MAE, RMSE, MAPE.
- Scheduling Quality: Success Rate, Utilization, Latency.

## 2. Runtime Benchmarks
- Inference Latency (P50/P95/P99).
- Model Load/Unload time.
- Resource footprint (RAM/VRAM).
