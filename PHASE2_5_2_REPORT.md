### 3.2 Logcat Search (Stage 2)
The captured logcat (via `adb logcat -d`) was searched for:
- `PackageInstaller`
- `PackageManager`
- `INSTALL_FAILED_USER_RESTRICTED`
- `user restriction`
- `security policy`

**Result**: The logcat output at the time of installation contains system-level events but no PackageInstaller/PackageManager entries related to this APK installation, because the installation was blocked at the OS level before the PackageManager could process the request. The error `INSTALL_FAILED_USER_RESTRICTED` is generated by the Android PackageManager when the user has not granted "Install unknown apps" permission for the sideloading source.

### 3.3 Root Cause Analysis

| Possible Cause | Evidence | Likelihood |
|---|---|---|
| "Install unknown apps" not enabled for ADB source | `INSTALL_FAILED_USER_RESTRICTED` is a standard Android 14 (SDK 36) MIUI error when the user has not permitted sideloading from ADB | **Very High** |
| MIUI security policy blocking ADB sideloading | Device runs MIUI V816 on Android 14; MIUI has additional permission prompts compared to stock Android | **High** |
| APK not signed with expected certificate | APK is correctly debug-signed with the debug keystore; signature validation passes | **Very Low** |
| Native library ABI mismatch | `lib/arm64-v8a/libocn_core.so` is present; CPU list includes `arm64-v8a` | **Very Low** |
| Package name conflict | `org.opencompute.network` is not a system package; no conflict detected | **Very Low** |

### 3.4 Determined Cause
**`INSTALL_FAILED_USER_RESTRICTED`** — the Android operating system has blocked installation because the user has not explicitly enabled sideloading from the ADB source. This is a security feature in Android 14 (SDK 36) on MIUI, and it **cannot** be bypassed programmatically or automatically from the host.
