## 4. Device-Side Restriction Diagnosis

### 4.1 Potential Factors
Based on MIUI V816 (Android 14) and the specific error:

1. **"Install via USB" (MIUI specific)**: MIUI has a specific setting called **"Install via USB"** (or similar, sometimes found in Developer Options) that *must* be toggled ON separately from "USB Debugging".
2. **"Verify apps over USB"**: Often found in Developer Options; can interfere with sideloading.
3. **"Install unknown apps"**: The standard Android setting; the user must trust the ADB installer or File Manager app.
4. **MIUI Security App**: The MIUI Security app may flag the sideloaded APK and prevent installation unless a "Continue" button is pressed manually on the device screen.

### 4.2 Required Manual User Actions (on Device)
1. **Developer Options Check**:
   - Go to **Settings** → **Additional Settings** → **Developer options**.
   - Ensure **USB debugging** is ON.
   - **CRITICAL**: Ensure **Install via USB** is toggled **ON**.
2. **Security App (MIUI specific)**:
   - If the installation dialog appears on the screen, do not rely on ADB. Look at the phone screen.
   - If MIUI Security prompts, click **"Continue"** or **"Install anyway"**.
3. **Install Unknown Apps**:
   - Ensure "Install unknown apps" is permitted for the source (e.g., File Manager).
