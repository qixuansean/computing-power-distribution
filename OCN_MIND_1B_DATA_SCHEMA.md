# OCN Mind 1B Data Schema

## 1. Core Data Structures
- **TaskDescriptor**: Metadata for incoming compute tasks.
- **NodeSnapshot**: Real-time resource state of an OCN node.
- **ResourcePredictionLabel**: Ground truth for training resource prediction.
- **SchedulingRecord**: Historical logs of scheduling decisions and outcomes.

## 2. Data Sources
- SIMULATED, REAL_DEVICE, HISTORICAL, SYNTHETIC.

## 3. Versioning
- Schema versioning (e.g., v1.0.0) with backward compatibility.
